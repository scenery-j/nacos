# バグの報告方法

Nacos プロジェクトのどの部分にバグやドキュメントの間違いがある場合でも、[issue を開く][Nacos-issue]ことでお知らせください。私たちはバグや間違いを非常に重く受け止め、どんな小さな問題でも重要だと考えています。誰でも対応できます。バグ報告を作成する前に、同じ問題を報告する issue が既に存在しないか確認してください。

バグ報告を正確かつ理解しやすくするため、次のようなバグ報告を作成してください：

- 具体的。可能な限り詳細を含めてください：バージョン、環境、設定など。Nacos サーバーの実行に関連するバグの場合は、Nacos ログを添付してください（Nacos 設定を含む起動ログは特に重要です）。

- 再現可能。問題を再現する手順を含めてください。一部の問題は再現が難しい場合があることを理解していますが、問題につながる可能性のある手順を含めてください。可能であれば、影響を受けた Nacos データディレクトリとスタックトレースをバグ報告に添付してください。

- 一意。既存のバグ報告を重複しないでください。

バグ報告を作成する前に、[良いバグ報告の書き方に関する Elika Etemad の記事][filing-good-bugs] を読むことをお勧めします。

バグを特定するために追加情報を求める場合があります。重複したバグ報告は閉じられます。

[etcd-issue]: https://github.com/etcd-io/etcd/issues/new
[filing-good-bugs]: http://fantasai.inkedblade.net/style/talks/filing-good-bugs/


# バグ報告の送信方法

Nacos プロジェクトのどの部分に問題やドキュメントの間違いがある場合でも、[issue を開く][Nacos-issue]ことでお知らせください。私たちはエラーと欠陥を非常に真剣に受け止め、製品に対して重要でない問題はありません。ただし、エラー報告を作成する前に、同じ問題を報告する issue が既に存在しないか確認してください。

バグ報告を正確かつ理解しやすくするため、次のようなバグ報告を作成してください：

- 詳細に具体的に。可能な限り詳細を含めてください：バージョン、環境、設定など。Nacos サーバーの実行に関連するエラーの場合は、Nacos ログを添付してください（Nacos 設定を含む起動ログは特に重要です）。

- 再現可能。問題を再現する手順を含めてください。一部の問題は再現が難しい場合があることを理解していますが、問題につながる可能性のある手順を含めてください。可能であれば、影響を受けた Nacos データディレクトリとスタックトレースをエラー報告に添付してください。

- 重複しない。既存のエラー報告を複製しないでください。

バグ報告を作成する前に、[良いバグ報告の書き方に関する Elika Etemad の記事][filing-good-bugs] を読むことをお勧めします。これにより役立つでしょう。

バグを特定するために追加情報を求める場合があります。重複したバグ報告は閉じられます。
