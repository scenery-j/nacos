# バグを報告する方法Nacos プロジェクトのいずれかの部分にバグやドキュメントの誤りがある場合は、[issue を開く][Nacos-issue]ことでお知らせください。私たちはバグや誤りを非常に重く受け止めており、どんな小さな問題でも重要だと考えており、誰でも問題を報告できます。バグ報告を作成する前に、同じ問題を報告する issue が既に存在しないか確認してください。

バグ報告を正確かつ理解しやすくするため、次の点に注意して作成してください：

- 具体的。可能な限り詳細を含めてください：バージョン、環境、設定など。Nacos サーバーの実行に関連するバグの場合は、Nacos ログ（特に Nacos 設定を含む起動ログ）を添付してください。
- 再現可能。問題を再現する手順を含めてください。一部の問題は再現が難しいことを理解していますが、問題につながる可能性のある手順を含めてください。可能であれば、影響を受けた Nacos データディレクトリとスタックトレースをバグ報告に添付してください。
- 一意。既存のバグ報告を複製しないでください。

バグ報告を作成する前に、[バグ報告の良い書き方に関する Elika Etemad の記事][filing-good-bugs] を読むことをお勧めします。

バグを特定するために追加情報を求めることがあります。重複したバグ報告は閉じられます。
