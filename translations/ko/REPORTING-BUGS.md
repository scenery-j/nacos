# 버그 보고 방법

Nacos 프로젝트의 어느 부분에 버그나 문서 오류가 있으면 [이슈 열기][Nacos-issue]을 통해 알려 주세요. 우리는 버그와 오류를 매우 심각하게 받아들이며, 어떤 문제도 작지 않다고 생각하고, 누구나 해결에 기여할 수 있다고 믿습니다. 버그 보고서를 만들기 전에, 동일한 문제를 보고하는 이슈가 이미 존재하는지 확인해 주세요.

버그 보고서를 정확하고 이해하기 쉽게 만들려면 다음과 같은 버그 보고서를 작성해 보세요:

- 구체적일 것. 가능한 많은 세부 정보를 포함하세요: 버전, 환경, 구성 등. 만약 버그가 Nacos 서버 실행과 관련이 있다면, Nacos 로그를 첨부해 주세요(Nacos 구성이 포함된 시작 로그가 특히 중요합니다).

- 재현 가능할 것. 문제를 재현하는 단계를 포함하세요. 일부 문제는 재현하기 어려울 수 있음을 이해하며, 문제를 일으킬 수 있는 단계를 포함해 주세요. 가능하면 영향을 받은 Nacos 데이터 디렉터리와 스택 strace를 버그 보고서에 첨부해 주세요.

- 고유할 것. 기존 버그 보고서를 중복하지 마세요.

버그 보고서를 만들기 전에 [Elika Etemad의 좋은 버그 보고서 작성 방법에 대한 글][filing-good-bugs]을 읽는 것이 도움이 될 수 있습니다.

버그를 찾기 위해 추가 정보를 요청할 수 있습니다. 중복된 버그 보고서는 닫히겠습니다.

[etcd-issue]: https://github.com/etcd-io/etcd/issues/new
[filing-good-bugs]: http://fantasai.inkedblade.net/style/talks/filing-good-bugs/


# 오류 보고서 제출 방법

Nacos 프로젝트의 어느 부분에 문제가 있거나 문서 오류가 있으면 [이슈 열기][Nacos-issue]을 통해 알려 주세요. 우리는 오류와 결함을 매우 심각하게 받아들이며, 제품 앞에서는 사소한 문제가 없습니다. 그러나 오류 보고서를 만들기 전에, 동일한 문제를 보고하는 이슈가 이미 존재하는지 확인해 주세요.

오류 보고서를 정확하고 이해하기 쉽게 만들려면 다음과 같은 오류 보고서를 작성해 보세요：

- 구체적으로. 가능한 많은 세부 정보를 포함하세요: 버전, 환경, 구성 등. 만약 오류가 Nacos 서버 실행과 관련이 있다면, Nacos 로그를 첨부해 주세요(Nacos 구성이 포함된 시작 로그가 특히 중요합니다).

- 재현 가능하게. 문제를 재현하는 단계를 포함하세요. 일부 문제는 재현하기 어려울 수 있음을 이해하며, 문제를 일으킬 수 있는 단계를 포함해 주세요. 가능하면 영향을 받은 Nacos 데이터 디렉터리와 스택 strace를 오류 보고서에 첨부해 주세요。

- 중복하지 않기. 기존 오류 보고서를 복사하지 마세요.

오류 보고서를 만들기 전에, 다음을 읽어 보는 것이 좋습니다: [Elika Etemad关于提交好错误报告的文章] [归档好错误] 이를 통해 영감을 얻을 수 있을 것입니다.

추가 정보가 필요할 경우 요청할 수 있습니다. 중복된 오류 보고서는 닫히겠습니다。
